# SCIA 2026 Highlight — Voiceover Script (ElevenLabs)

**Voice direction:** confident, warm, premium broadcast. Think a keynote announcer, not a movie trailer.
Mid-low register, unhurried, with a slight smile on the last line.
ElevenLabs settings to start from: Stability ~45%, Similarity ~75%, Style ~20%, Speaker Boost on.
Generate each line as its **own clip** so you can drop it exactly on its timecode.

The opening (0:00–0:10) has no VO: Intel's "from firefighting to foresight" plus the proof montage carry it. The VO only lives in the gaps. Every other second is a finalist speaking, so the VO never talks over them.
